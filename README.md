## 🚀 लोकल में चलाने के निर्देश (How to Run)

```bash
# 1. रिपॉजिटरी क्लोन करें
git clone https://github.com/devendra257/chandrashekhar_wedding.git
cd chandrashekhar_wedding

# 2. डिपेंडेंसीज इंस्टॉल करें
npm install

# 3. सर्वर स्टार्ट करें
npm start
# या
node server.js
```

ब्राउज़र में खोलें:
- **वेडिंग इनविटेशन:** `http://localhost:3000/`
- **प्राइवेट एडमिन एडिटर:** `http://localhost:3000/admin`
